# Сборка и деплой

[← Главная документация](../README.md)

## Сборка

```bash
npm run build
```

Команда проверяет TypeScript и создаёт production-сборку Vite в `dist`. Она используется и для тестового стенда. Место размещения приложения определяется настройками деплоя.

## CI/CD

Workflow находится в `.github/workflows/ci-dev.yml`.

| Событие                  | Действия                                                                                         |
| ------------------------ | ------------------------------------------------------------------------------------------------ |
| Pull request в `develop` | Установка зависимостей через `npm ci`, проверка ESLint, прямых URL, TypeScript и сборка.         |
| Push в `develop`         | Те же проверки, затем сборка и публикация Docker-образа, деплой на тестовый стенд и healthcheck. |

Деплой выполняется после успешного прохождения предыдущих этапов.

## Docker и Nginx

Dockerfile собирает приложение на Node.js 24 командой `npm run build`. Готовые файлы из `dist` обслуживает Nginx; его конфигурация находится в `nginx.conf`.

CI обновляет сервис Docker Swarm на тестовом стенде.
