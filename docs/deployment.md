# Сборка и деплой

[← Главная документация](../README.md)

## Сборка

```bash
npm run build
```

Команда проверяет TypeScript и создаёт production-сборку Vite в `dist`. Она используется и для тестового стенда. Место размещения приложения определяется настройками деплоя.

## CI/CD

Workflow находится в `.github/workflows/ci-dev.yml`.

| Событие                  | Действия                                                                                                          |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------- |
| Pull request в `develop` | Установка зависимостей через `npm ci`, проверка ESLint, форматирования Prettier, прямых URL, TypeScript и сборка. |
| Push в `develop`         | Те же проверки, затем сборка и публикация Docker-образа, деплой на тестовый стенд и healthcheck.                  |

Деплой выполняется после успешного прохождения предыдущих этапов.

Workflow отдельно запускает `npm run lint`, `npm run format:check`, `npm run check:no-direct-urls` и `npm run build`; последняя команда включает проверку TypeScript. Проверка форматирования не изменяет файлы: если она завершится с ошибкой, исправления нужно внести локально и закоммитить.

Steiger пока не включён в CI: архитектурные замечания исправляются постепенно. Локальный запуск описан в [разделе проверки FSD](development.md#проверка-архитектуры-fsd).

## Docker и Nginx

Dockerfile собирает приложение на Node.js 24 командой `npm run build`. Готовые файлы из `dist` обслуживает Nginx; его конфигурация находится в `nginx.conf`.

CI обновляет сервис Docker Swarm на тестовом стенде.
